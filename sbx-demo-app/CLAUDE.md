# CLAUDE.md

- Install dependencies with `pip install -r requirements.txt`; run the tests with `pytest`.
- Feature specs live in `specs/`. Branch from `main` as `feat/<spec-id>`, e.g. `feat/001-discount-codes` for `specs/001-discount-codes.md`.
- Commit messages use the conventional style (`feat: ...`, `fix: ...`, `test: ...`).
